# Quiz-App
An interactive Frontend Quiz Application built with HTML, CSS, and JavaScript. It features a timer for each question, auto-switching when time runs out, and a persistent leaderboard using localStorage!
# ✨ Features

📋 Dynamic Questions and Options

⏳ 10-second Timer for each question

🚀 Auto move to next question when timer ends

🏆 Leaderboard to save and display top 5 scores

🖥️ Responsive Design for mobile and desktop

🔄 Restart Quiz button to play again

🔥 Smooth UX with button hover effects and transitions

# 🛠️ Built With

HTML5

CSS3

Vanilla JavaScript (No frameworks)
